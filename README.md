# Educational ARES
Educational ARES is a fork of the [ARES OS Repository](https://github.com/AFRL-ARES/ARES) modified to work with a Prusa MK4S 3-D Printer and a USB camera. 

## Install
To install Educational ARES, we recommend downloading the [ARES Launcher](https://github.com/AFRL-ARES/ARES-Launcher) and following the provided documentation to install and manage your ARES instance.
